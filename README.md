# Employee Management System

A very simple employee management website made with HTML, CSS and JavaScript.

## Features
- Add an employee with a name and department
- View the employee list
- Delete an employee
- Save employee data in browser local storage

## How to run
1. Extract the ZIP file.
2. Open the `EmployeeManagementSystem_Web` folder.
3. Double-click `index.html`.
4. The application opens in your web browser.

No installation or internet connection is required.

## Files
- `index.html` - webpage structure
- `style.css` - webpage design
- `script.js` - application functionality
